### Idea 1: TimeCapRL: Decoupling Time-Series Perception and Reasoning via QA-Reward Reinforcement Learning

**Core novelty claim**: The first application of the CapRL (accuracy-as-reward) paradigm to time-series, isolating TS-to-text perception from reasoning to directly penalize ungrounded hallucinated captions.

**Description**: Standard synthetic SFT (like OpenTSLM) suffers from next-token loss ignoring the input TS geometry in favor of text priors. This idea directly ports CapRL to the time-series domain. The architecture splits into a TS-captioner (Chronos-2 + Qwen) and a frozen, vision-free reasoning LLM (gpt-5.4-mini). The captioner generates a description, the frozen LLM attempts a downstream QA task (e.g., TSShapeQA), and the discrete QA accuracy serves as the reward signal to update the captioner via PPO/GRPO. This explicitly forces the captioner to encode discriminative features of the specific input rather than memorizing a synthetic distribution.

**Technical approach**:
- PPO/GRPO optimization of the TS-LLM cross-attention and text layers, using downstream multiple-choice QA accuracy as the primary reward.
- A frozen strong reasoning model (e.g., gpt-5.4) acts as the environment, evaluating the generated captions.
- Length-penalty and formatting auxiliary rewards to keep the captions concise and parseable for the reasoning model.

**Why it matters**: It offers a mathematically principled fix to the caption collapse you observed, providing the strongest baseline for RL-aligned TS-LLMs over pure SFT approaches like ChatTS.

**Main risks**: High variance in RL optimization over long discrete text sequences; the frozen text-LLM might be too robust, guessing correct answers from partial or noisy captions and flattening the reward gradient.

**Venue fit**: ICLR main / NeurIPS main


### Idea 2: The Illusion of Grounding: Synthetic Caption SFT Fails Counterfactual Probes in Time-Series LLMs

**Core novelty claim**: The first rigorous negative-result paper demonstrating that standard synthetic-caption SFT induces mode collapse and fails fundamentally at shape-primitive perception.

**Description**: This is a direct formalization of your kill-test. Despite recent hype around models like OpenTSLM and ChatTS, we hypothesize that mapping continuous series to text using next-token prediction inherently biases the model toward linguistic priors rather than sensory grounding. This paper publishes the exact counterfactual probe results (time reversal + variance injection), revealing the 2.78% flip rate. It formally defines "caption collapse" mathematically and empirically proves that `learned_caption ≈ wrong_caption` for SFT models across both in-dist and OOD benchmarks. 

**Technical approach**:
- Extensive empirical ablation of the trained OpenTSLM model on your TSShapeQA benchmark.
- Introduction of the "Counterfactual Flip Rate" (CFR) metric to measure true input conditioning.
- KL-divergence analysis between the output distributions of the model given original vs. corrupted inputs to quantify mode collapse.

**Why it matters**: The field is currently wasting millions of GPU hours generating larger synthetic datasets (like ChatTS). A strong negative result saves the community from a dead end and redirects focus to objective functions.

**Main risks**: Pure negative results are sometimes rejected by reviewers who demand a "fixed" state-of-the-art model alongside the diagnosis.

**Venue fit**: ICLR main (Spotlight potential) / NeurIPS main


### Idea 3: ShapeShift-TS: A Counterfactual Benchmark for Shape-Primitive Perception in Time-Series Foundation Models

**Core novelty claim**: The first OOD benchmark combining length-controlled shape-primitive perception with paired counterfactuals (e.g., time reversal, variance injection) to test TS-LLM input conditioning.

**Description**: Current benchmarks (like TRQA or ECG-QA) test downstream reasoning accuracy, which we know strong LLMs can guess without looking at the time-series. ShapeShift-TS provides a purely diagnostic dataset where every original time-series (Trends, Extrema, Volatility) is paired with a mathematically transformed counterfactual that fundamentally alters the ground-truth text label. Models are evaluated not just on absolute accuracy, but on their consistency matrix (Correct Original AND Correct Counterfactual), exposing models that randomly guess or rely on priors.

**Technical approach**:
- Curation of a clean, length-controlled dataset focusing purely on primitives (TREND/EXTREMA/VOLATILITY).
- Procedural generation of deterministic counterfactual pairs via phase shifting, amplitude scaling, and time-reversal.
- Scoring pipeline that weights the "Consistency Rate" higher than absolute isolated accuracy.

**Why it matters**: Provides the community with the exact missing tool needed to quickly verify if their new TS-LLM architecture has overcome the caption collapse problem before they waste compute on full medical/finance datasets.

**Main risks**: Benchmark papers require extensive baselining of *all* available models (TimesFM, Chronos, OpenTSLM, ChatTS) to prove utility.

**Venue fit**: NeurIPS Datasets and Benchmarks Track


### Idea 4: Step-by-Step Shape Perception: Verifiable Process Reward Models for Multi-Step Time-Series Reasoning

**Core novelty claim**: Adapts math-style Process Reward Models (PRMs) to time-series by scoring intermediate shape-primitive extraction steps rather than relying solely on outcome RL.

**Description**: Borrowing from the math reasoning literature (e.g., OpenAI's Let's Verify Step-by-Step), this idea structures TS captioning as a multi-step chain-of-thought process. First step: Global Trend. Second Step: Local Extrema. Third Step: Volatility. Instead of optimizing the entire sequence via standard RL or SFT, we train a Process Reward Model that scores each *step* of the caption generation against heuristic rules (e.g., checking if the extracted peak value actually exists in the raw array). The TS-LLM then uses Best-of-N sampling or tree-search against this PRM.

**Technical approach**:
- Construction of step-level synthetic labels from the LTSGen pipeline.
- Training a distinct TS-PRM (a smaller encoder-only model) to output a scalar reward per generation step.
- Inference-time search (Best-of-N or MCTS) using the TS-PRM to guide the TS-LLM out of mode collapse.

**Why it matters**: It bypasses the sparsity of QA-based outcome rewards (CapRL) by providing dense, verifiable feedback directly tied to mathematical properties of the sequence.

**Main risks**: High engineering overhead to define and verify intermediate steps; inference time scales linearly with search depth.

**Venue fit**: ICML main / ICLR main


### Idea 5: Causal Time-Series Captioning via Variational Information Bottlenecks

**Core novelty claim**: Introduces a Variational Information Bottleneck (VIB) objective to TS-text cross-attention that maximizes mutual information between the TS input and caption while explicitly penalizing reliance on linguistic priors.

**Description**: Borrowing from information theory, the caption collapse is framed as a failure of mutual information: $I(Text_{out}; TS_{in})$ is vanishingly small. We modify the OpenTSLM training objective by adding an Information Bottleneck loss. We train a parallel "text-only prior" model. The main model is penalized if its output distribution is too similar to the text-only prior's distribution, forcing the TS cross-attention heads to transmit novel, discriminative features from the Chronos-2 patches to minimize the loss.

**Technical approach**:
- Standard next-token SFT loss is regularized by $D_{KL}(P(y|x_{TS}, y_{<t}) || P(y|y_{<t}))$.
- Implementation of an auxiliary contrastive loss at the Flamingo cross-attention layer to maximize feature divergence from unconditional text states.
- Empirical evaluation proving this elevates the counterfactual flip rate significantly compared to vanilla SFT.

**Why it matters**: Provides a direct, differentiable loss-function fix to SFT without requiring the complexities and instability of full Reinforcement Learning.

**Main risks**: Balancing the IB coefficient ($\beta$) is notoriously finicky; too high and the model generates gibberish, too low and it collapses back to SFT.

**Venue fit**: ICML main / ICLR main


### Idea 6: Echoes in the Sequence: Evaluating TS-LLMs against Label-Shuffled Oracles

**Core novelty claim**: A diagnostic dataset and evaluation framework that quantifies an LLM's reliance on linguistic priors by measuring QA accuracy drops when feeding label-shuffled and mismatched oracle captions.

**Description**: This is a diagnostic companion piece. If your kill-test showed that `learned_caption ≈ wrong_caption` in downstream QA, this idea generalizes that into a formal evaluation protocol. It creates a dataset where true TS data is paired with explicitly *adversarial* or label-shuffled captions. The test is: when the text says "upward trend" but the data is "downward trend," what does the downstream QA model answer? This isolates the exact percentage of "hallucinated reasoning" inherent to the LLM versus true multimodal integration.

**Technical approach**:
- Creation of an adversarial test set containing original TS and manually perturbed, highly plausible but incorrect oracle captions.
- Evaluation of the baseline frozen OpenTSLM checkpoint against this dataset.
- Formal definition of an "Alignment Coefficient" to quantify text-vs-TS reliance.

**Why it matters**: It fundamentally challenges the evaluation methodology of every TS paper claiming high accuracy, proving they are actually just measuring LLM prior-guessing.

**Main risks**: Needs a very large, diverse set of datasets to be conclusive.

**Venue fit**: EMNLP short / ACL main


### Idea 7: Contrastive Decoding Rescues Collapsed Time-Series Captions from Frozen SFT Models

**Core novelty claim**: Uses a frozen, already-trained OpenTSLM checkpoint and applies inference-time contrastive decoding against a text-only prior to successfully extract grounded TS shape descriptions without large-scale pretraining.

**Description**: This directly uses the frozen OpenTSLM checkpoint from your kill-test. You discovered it fails the counterfactual probe. Instead of retraining it with RL or IB, we hypothesize the visual/time-series grounding *is* present in the hidden states but is simply overpowered by the LM's text prior during autoregressive generation. We adapt Contrastive Decoding (CD) from NLP/Vision, penalizing tokens predicted strongly by a text-only LLM prior (e.g., Qwen3-4B without Chronos). By maximizing the log-probability difference at inference time, the model is forced to emit only tokens conditioned on the time-series.

**Technical approach**:
- Loading the *already trained* OpenTSLM checkpoint and freezing it.
- Loading a smaller text-only prior model.
- Implementing contrastive decoding: $P_{CD}(x) \propto softmax(logits_{OpenTSLM} - \alpha \cdot logits_{prior})$.
- Running the generated captions through the counterfactual probe.

**Why it matters**: It is an incredibly cheap, zero-shot fix that rescues collapsed SFT models without the massive compute required to re-run the 55k synthetic caption training.

**Main risks**: CD can sometimes severely degrade the fluency of the generated text, rendering it useless for downstream QA.

**Venue fit**: ICLR main / EMNLP main


### Idea 8: Adversarial TS-LLM Debate for Robust Counterfactual Grounding

**Core novelty claim**: Employs a multi-agent LLM debate protocol where an adversarial "critic" model actively attempts to highlight counterfactual hallucinations in a "describer" model's generated time-series caption.

**Description**: Borrowing from self-play and debate in LLM reasoning, we structure the captioning process as a dialogue. The main TS-LLM generates a caption. A second, adversarial LLM (perhaps the frozen text-LLM, given access to tools like simple min/max Python snippets) critiques the caption, searching for contradictions. If the critic finds one (e.g., "You claimed the peak is at index 40, but the data max is at index 10"), the describer must revise. This explicitly introduces the counterfactual test directly into the generation loop.

**Technical approach**:
- Iterative generation where the Describer produces a draft text.
- The Critic (using a deterministic evaluator like python or a fine-tuned critic LLM) verifies constraints.
- Multi-turn refinement before passing the final caption to the downstream QA task.

**Why it matters**: Directly integrates verification without requiring RL or custom loss functions, leveraging the reasoning capabilities of stronger text models (like gpt-5.4-mini) to correct the TS-LLM.

**Main risks**: High inference latency due to multi-turn dialogue per sequence; critic model might hallucinate flaws in correct captions.

**Venue fit**: ICML main / ACL main


### Idea 9: RAG-TS: Anchoring Time-Series Generation via Differentiable Retrieval of Empirical Signatures

**Core novelty claim**: Enhances TS-LLMs with a differentiable retrieval mechanism over a datastore of canonical shape primitives, breaking SFT mode collapse by forcing generation to condition on exact empirical examples rather than parametric cross-attention.

**Description**: Inspired by RAG and kNN-LMs, we hypothesize that continuous TS-embeddings (Chronos-2 patches) struggle to firmly anchor discrete text tokens. This approach builds a datastore of specific, well-labeled shape primitives from the LTSGen pipeline. Given a new input, the model retrieves the k-nearest canonical shapes (e.g., 'textbook downward step-function') in the Chronos embedding space. The LLM conditions its text generation explicitly on these retrieved, hard-coded text anchors alongside the continuous input, dramatically reducing hallucination.

**Technical approach**:
- Construct a dense FAISS index of canonical TS embeddings and their oracle captions.
- Modify the OpenTSLM architecture to include a retrieval module that prepends retrieved textual anchors into the prompt.
- Train the query encoder via a contrastive loss to pull embeddings closer to their canonical shape prototypes.

**Why it matters**: Provides explicit, discrete grounding that parametric SFT lacks, directly solving the synthetic mode collapse by borrowing from the stability of retrieval-augmented generation.

**Main risks**: The quality of the retrieval index entirely bounds the performance; if a novel shape is encountered, the model might fail catastrophically.

**Venue fit**: ICLR main / KDD main


### Idea 10: Neurosymbolic Concept Bottlenecks for Interpretable Time-Series Perception

**Core novelty claim**: Forces the continuous TS-encoder to explicitly output discrete, neurosymbolic truth values for primitive shape properties (e.g., `is_monotonic=True`) via a differentiable logical loss before text generation occurs.

**Description**: To directly fix the failure of the counterfactual probe, we insert a Concept Bottleneck Layer between Chronos-2 and the LLM. Instead of directly projecting patches to text tokens, the model must first classify discrete, deterministic boolean logic concepts derived from the synthetic data (e.g., `has_spikes`, `positive_trend`, `extrema_count=3`). The text generation is then conditioned entirely on these grounded, interpretable symbolic concepts. If the counterfactual test flips a peak to a trough, the explicit bottleneck classification flips, guaranteeing the caption changes.

**Technical approach**:
- Define a schema of logical concepts across all LTSGen synthetic datasets.
- Train the projection layer with a multi-task binary cross-entropy loss against these deterministic concepts alongside the standard next-token loss.
- Inference generation conditioned on the explicitly predicted concept vector.

**Why it matters**: It formally guarantees that if the input shape geometry changes in a meaningful way, the continuous representation explicitly registers it before the text LLM's priors can smooth it over.

**Main risks**: Requires significant manual engineering of the concept ontology; the bottleneck might be too restrictive, destroying the model's ability to describe complex, non-primitive real-world medical or financial data.

**Venue fit**: NeurIPS main / ICML main
