## Baseline Paper

**OpenTSLM: Time-Series Language Models for Reasoning over Multivariate Medical Text- and Time-Series Data**
(Stanford + ETH + Google + Amazon, arXiv 2510.02410, 2025-10)
Link: https://arxiv.org/abs/2510.02410
Code: https://github.com/StanfordBDHG/OpenTSLM

**Method (3 sentences):** Integrates time series as native modality in pretrained LLM via two variants — soft-prompt (concat learnable TS tokens with text tokens) and Flamingo cross-attention (gated cross-attn over Chronos-2 patch embeddings). Trains on three custom CoT datasets (HAR-CoT, Sleep-CoT, ECG-QA-CoT) with next-token LM loss on reference CoT traces. Reports +60pp F1 over finetuned text-only models on sleep staging and HAR, surpassing GPT-4o.

**What OpenTSLM does NOT do:**
- No ablation of caption utility on held-out external QA benchmarks
- No counterfactual probe verifying the TS encoder conditions on input shape
- Training objective = standard next-token LM loss (no RL, no contrastive)
- Medical-only; no shape-primitive perception evaluation

## Literature Context (compressed 1 page)

Field split into 4 camps in 2024-2026:

1. **Synthetic-caption SFT** (OpenTSLM, ChatTS VLDB 2025, LTSGen): crowded, well-published, saturating.
2. **Numeric tokenization** (Chronos, TimesFM, Time-LLM): bypasses language entirely.
3. **Contrastive TS↔text** (TS-CLIP EMNLP 2025): solves label collapse with synonym bank; does not generate text.
4. **Tool-augmented agents** (TimeART, DCATS): LLM routes to TS tools; bypasses TS perception.

Closest published works with same stack as user:
- **ChatTS** (2412.03104): synthetic Evol-Instruct + SFT. +46% alignment / +25.8% reasoning over GPT-4o. Open-source 14B.
- **TimeMaster** (2506.13705): Qwen2.5-VL-3B + SFT + GRPO with composite reward (format + classification + LLM-judged insight). +14.6% over classical on TimerBed classification.
- **TS-CLIP** (EMNLP 2025): first TS-text contrastive foundation; synonym bank for label collapse.
- **TimeART** (2601.13653): agentic TSQA with 21 tools.
- **TRQA** (OpenReview ULQt51DRug): 6-task benchmark splitting conventional vs advanced TS reasoning.

**Critical empirical findings from user's own kill-test (unpublished, highly relevant):**
- Oracle caption → downstream LLM QA: 96-100%
- OpenTSLM-trained caption → downstream LLM QA: 36% (n=50 OOD, n=50 in-dist)
- Wrong (label-shuffled) caption → QA: 38%
- `learned_caption ≈ wrong_caption` confirmed both in-dist and OOD
- Counterfactual probe (time reversal + variance injection, n=36): learned caption correctly flips for only **2.78%** of paired inputs — the captioner essentially does not condition on input shape
- Root cause: next-token LM loss on reference caption has no mechanism forcing the generated caption to encode discriminative features of the specific input

**Empirically-observed open niche:**
- No TS paper ports **CapRL's** (ICLR 2026, 2509.22647) paradigm: caption → vision-free LLM → MCQ → accuracy-as-RL-reward. TimeMaster has RL but not this decoupled probe-as-reward structure.
- No published TS benchmark combines length-controlled shape-primitive perception + OOD-only splits + counterfactual probe protocol.
- No paper publishes a rigorous negative result on synthetic-caption SFT failing the counterfactual probe.
