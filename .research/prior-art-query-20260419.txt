=== IDEA (three-part composite paper) ===

Title: "ShapeShift: Diagnosing, Benchmarking, and Fixing Counterfactual
Collapse in Time-Series Language Models"

Contribution 1 — DIAGNOSIS. Formally define a "correct-flip rate" (CFR) for
a time-series captioner C under a known semantics-altering transform T:
given paired (x, T(x)) with known ground-truth labels that differ under T,
CFR is the fraction of pairs on which C's output correctly flips. Empirically
measure CFR across multiple synthetic-caption-SFT TS-LLMs (OpenTSLM-SoftPrompt,
OpenTSLM-Flamingo, ChatTS-14B) on a transform taxonomy (time reversal,
variance injection, amplitude scale, phase shift, local permutation, spike
insert/remove, trend inversion, monotonic→non-monotonic). Report that typical
CFR is <10% across all tested TS-LLMs.

Contribution 2 — BENCHMARK. Release "ShapeShift-TS", a counterfactual-paired
TS-QA benchmark: 4-5 shape primitives (trend, extrema, volatility,
periodicity, changepoint) × 6-8 transforms × length buckets
(128 / 256 / 512 / 1024). Primary metric = consistency rate (both original
and counterfactual answered correctly). Validated to predict held-out
shape-sensitive QA on real OOD data (Time-MMD, exchange_rate, illness).

Contribution 3 — METHOD. Introduce **Counterfactual-Pair Reward (CPR)**:
an RL reward for TS captioners that augments CapRL-style downstream-QA
accuracy reward with a paired-counterfactual consistency reward. Given a
paired batch (x, T(x)) with flip-expected ground-truth, the captioner is
rewarded both when (a) the frozen downstream text-only LLM answers MCQs
correctly from each caption (CapRL-like) and (b) the captions' answer
distributions differ in the ground-truth-expected semantic direction between
original and counterfactual. Loss = alpha * QA_accuracy_reward(x) +
beta * counterfactual_pair_consistency_reward(x, T(x)).

The key NOVELTY claim over the most obvious prior art:
- CapRL (ICLR 2026) uses only QA-accuracy reward on a single image. We add
  paired-counterfactual consistency reward. TS allows natural label-flipping
  transforms that vision does not, motivating this extra term.
- TimeMaster (2506.13705) uses composite reward = format + classification
  accuracy + LLM-judged insight quality. It does NOT use a counterfactual
  pair probe as reward, and is classification-target rather than
  caption-for-downstream-QA.
- TS-CLIP (EMNLP 2025) uses contrastive TS-text with a synonym bank but
  does not generate text and does not use a downstream QA probe.
- OpenTSLM (arXiv 2510.02410) and ChatTS (VLDB 2025) use only SFT with
  synthetic captions — no RL, no counterfactual probe.
